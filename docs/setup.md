# The Four-Step Setup

Let's get Fresh Breath up and going so you can try it out. (It's a **personal
app server** — a place where little personal tools can live together and share authentication, storage, and integrations.

> *Personal* not *public*. Don't just host this on the Internet!!

## What it's for

Do you write lots of little apps — blogging tools, feed readers, task trackers,
calendar tools — that need some storage, some auth, some access? Fresh Breath
sits underneath them all:

- **Static is so simple.** Keep everything client-side, in pure static HTML,
  where possible. All external connections are handled by Fresh Breath.
- **A box of integrations** (think N8N or Zapier) but with the flexibility of
  actual client-side code to tie things together, rather than restrictive
  no-code platforms.
- **People log in with their own creds.** No sessions are kept in Fresh
  Breath's database — your coworkers' creds stay in their browsers.

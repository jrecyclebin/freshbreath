# Fresh Breath

*Souping Up Static HTML Apps*

Fresh Breath is an app server designed to give flexiblity to standalone HTML
apps - or any other app that needs third-party connections, auth or an SSH agent.
This skill will get you up to speed on how to use Fresh Breath from your HTML
apps.

Here's the toolkit available in this skill:

- If you are setting up an app to authenticate - this could be an OIDC login,
  an API or MCP login - or Fresh Breath's internal SSH key generation and login,
  see the Auth Guide at 'guides/auth.md' inside of this skill.

- If you want to read more specifically about managing SSH keys and how you can
  use Fresh Breath's API to log-in and start sessions with remote servers,
  transfer files or use Git, see the 'guides/ssh.md'.

- For publishing apps to be hosted by your Fresh Breath, see the
  'guides/publishing.md'.

It's best to have an App nonce for the app you're working on and the Fresh
Breath URL that indicates how to reach the API and frbr.js.

# Some General Knowledge

The default Fresh Breath runs on `http://localhost:9009`  - however, HTTPS can
be configured quite easily with mkcert and is highly recommended.

Every app needs a nonce - this is a unique identifier for your app that is
generated by the Fresh Breath server and is used to give it access. You can find
your app's nonce by going to the Fresh Breath control panel and going to the
"Apps" section. Every app's nonce is listed directly under its name.

Users do not need to be listed in Fresh Breath to use an app - they'll
authenticate using their own permissions (to Github, to an OIDC provider, etc.)
and you can choose to limit access in your app's logic if you want to.

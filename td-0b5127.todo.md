# Service File Publishing (td-0b5127)

Generalize app web-file publishing so Admin+ users can publish files for any
service, not just hosted apps. This unlocks remote management of `tasks` and
`virtual` service definitions through the same transfer-token flow used by app
web files.

## Clarifications

- `tasks`/`virtual` files stay in their existing directories (`tasks/<name>.txt`,
  `virtual/<name>.txt`) so they remain categorized and readable by name.
- No ZIP uploads for `tasks`/`virtual` — these are single plain-text files.
- Skip `list_service_files` MCP tool for now.
- Do not update `skills/freshbreath/guides/publishing.md` — a separate guide is
  planned.

## Relevant Files

- `xfer.go` — transfer tokens; needs service-target dispatch.
- `admin_core.go` — add `core*ServiceFiles` ops.
- `handler.go` — add `/api/services/{id}/files` sub-route.
- `mcp_central.go` — add service file MCP tools and `service_xfer_fallback`.
- `virtual.go` / `handler.go` — reload virtual/tasks definitions after upload.
- `admin_core_test.go` — unit tests for core ops.
- `server_test.go` — handler tests for new routes.
- `mcp_xfer_test.go` or `mcp_central_test.go` — MCP tool tests.
